# NIS Smart Hub

Интерактивный локальный прототип школьного приложения. Для работы Gemini нужен Node.js. Запустите `START.cmd`, затем откройте `http://127.0.0.1:4174`. Не открывайте `index.html` напрямую: запросы AI работают через локальный сервер.

Демо включает две роли, недельное расписание, учебную аналитику, чат с Gemini в двух режимах, генерируемую шпаргалку, мини-квиз, бронирование кабинетов, домашние задания, события, идеи и справочник учителей. Выбор роли, отметки, заметки и бронирования хранятся в `localStorage` браузера.

В разделе «Расписание» ученик может выбрать любой из 61 классов PDF (например, 8L или 7K). Предметы, номера уроков, время, кабинеты и сокращения преподавателей извлечены из `students.pdf`. Выбранный класс сохраняется в браузере и используется на главной странице. Начальный класс — 8A.

В режиме учителя доступны личное расписание по номерам уроков, журнал оценок, назначение ДЗ для класса и бронирование кабинета. Переключение в эту роль требует PIN из строки `TEACHER_PIN` в локальном `.env`. Ученик видит только свои оценки, задания класса 8 «А» и занятость кабинетов; бронирование ученику недоступно. В «Бюро находок» можно сфотографировать или выбрать изображение вещи, указать место и описание; объявление с уменьшенным фото хранится в браузере. На мобильном устройстве выбор изображения может открыть камеру.

Ключ Gemini хранится в `.env` и читается только сервером. Не публикуйте этот файл и не добавляйте его в Git. При переносе проекта на другой компьютер создайте `.env` по образцу `.env.example`. Модель можно поменять в переменной `GEMINI_MODEL`.

Личное расписание учителя, статусы кабинетов, даты будущих проверок и прочая аналитика являются демонстрационными. Ученическое расписание взято из PDF. Некоторые сокращения предметов оставлены как в оригинале. Для синхронизации между пользователями, реальных контактов и хранения загруженных файлов потребуется база данных и дополнительные серверные маршруты.

PIN ограничивает обычный вход в режим учителя в локальном прототипе. Для настоящей школы потребуются персональные аккаунты и хранение оценок, заданий и объявлений на сервере с проверкой прав доступа. Сейчас эти записи видны в рамках одного браузера.
